llm-gateway

A signed apk feed for OpenWrt 25.12 with llm-gateway: the models of the house behind one name on the router, a key per device, HTTPS under the router's own CA and a journal without content.

Package: llm-gateway 0.1.0-r4, built by CI run 42379581827 from commit 6f623c4.

Add the feed

On the router, as root. The first line trusts the key, the third adds the feed for the router's own architecture.

wget -O /etc/apk/keys/llm-gateway.pem https://taipanbox.github.io/openwrt-llm-gateway/llm-gateway.pem
sha256sum /etc/apk/keys/llm-gateway.pem
echo "https://taipanbox.github.io/openwrt-llm-gateway/25.12/$(cat /etc/apk/arch)/packages.adb" >> /etc/apk/repositories.d/customfeeds.list

apk update && apk add llm-gateway

The key's SHA-256, which sha256sum must print:

d5151976fb774d291b4954cce7ea86cf4cf25de6c616c3fbbf05fd5a531457fa

The index and every package are signed with that key, so nothing above needs --allow-untrusted. Without the key apk drops the feed without a word and the package appears not to exist. The service does nothing until it is configured; the README goes on from there.

Architectures

  • aarch64_cortex-a53: has run on a GL.iNet Flint 2
  • arm_cortex-a7_neon-vfpv4: built and signed
  • mipsel_24kc: built and signed
  • x86_64: has run on OpenWrt 25.12.5 in a virtual lab
